# سجدة | Sujda

منصة إسلامية عربية (Angular 19 + PWA) للقرآن الكريم والأذكار ومواقيت الصلاة والمسبحة.

تعمل بدون حساب. البيانات الشخصية تُحفظ محليًا على الجهاز.

## التشغيل

```bash
npm install
npm start
```

يفتح على `http://localhost:4200`.

```bash
npm run build
```

مخرجات الإنتاج في `dist/sujda/browser`.

```bash
npm test -- --watch=false --browsers=ChromeHeadless
```

## المصادر

| البيانات | المصدر | الاستخدام |
| --- | --- | --- |
| نص القرآن العثماني | [AlQuran Cloud](https://alquran.cloud) عن Tanzil | قائمة السور والآيات والبحث |
| التلاوات | `cdn.islamic.network` عبر نفس الخدمة | ملفات MP3 للآيات |
| التفسير الميسر / الجلالين | AlQuran Cloud | صفحة التفسير |
| مواقيت الصلاة | [Aladhan](https://aladhan.com/prayer-times-api) | حساب المواقيت |
| التاريخ الهجري | Aladhan مع بيانات اليوم | التقويم |
| الأذكار | نصوص مشهورة مما في حصن المسلم مع ذكر المصدر | مكتبة محلية ثابتة |
| الأحاديث | [HadeethEnc](https://hadeethenc.com) | تصفح بالمصنّفات والفرز محليًا |
| راديو القرآن | [mp3quran](https://mp3quran.net) API v3 | البث المباشر وقائمة احتياطية |
| الرقية | نص قرآني من AlQuran + أدعية محلية | الرقية الشرعية |
| القصص | نصوص محلية موثّقة | قصص الأنبياء |

لا تُضمَّن مفاتيح سرية. واجهات البرمجة المستخدمة عامة.

## PWA والتثبيت

- Manifest: `public/manifest.webmanifest`
- Service Worker: يُفعَّل في بناء الإنتاج عبر `@angular/service-worker`
- على Chromium: نافذة `beforeinstallprompt`
- على iPhone/iPad: المشاركة ثم «إضافة إلى الشاشة الرئيسية»

الإشعارات:

1. تنبيه داخل الصفحة عندما يكون الموقع مفتوحًا.
2. إشعار المتصفح بعد منح الإذن.
3. Web Push عند إغلاق التطبيق **غير مفعّل** لأنه يحتاج خادم اشتراك. الواجهة توضح ذلك صراحة.

## الميزات المكتملة

- ترحيب بدعاء شخصي (قابل للتعديل/التعطيل)
- لوحة رئيسية: المواقيت، الورد، الأذكار، المسبحة، آخر موضع
- القرآن: 114 سورة، بحث، علامات، ملاحظات، مفضلة، تلاوة، تفسير، خطة ختمة
- القرآن صوتيًا: اختيار القارئ ونطاق السور، تكرار المقطع، ضبط السرعة، ومشغّل ثابت أسفل الشاشة
- الأحاديث: تصفح بالمصنّفات مع عرض الدرجة والمصدر
- الرقية الشرعية والقصص: نصوص موثّقة مع تنبيهات
- اختبار المعلومات الإسلامية: أسئلة، نتائج، نقاط يومية
- راديو القرآن: بث مباشر مع قائمة احتياطية
- المساعد: تنقّل واقتراح أقسام محليًا (لا فتاوى ولا نصوص مُولّدة)
- الأذكار بعدّاد ووضع قراءة متتابع
- مسبحة مع هدف وسجل واهتزاز اختياري
- مواقيت حسب مدينة أو موقع، وطريقة حساب ومذهب، وتنبيهات لكل صلاة وإقامة وأصوات
- صفحة العمل دون اتصال توضّح ما هو متاح محليًا وما يحتاج شبكة
- تذكيرات محلية، قبلة، تقويم، أسماء الله الحسنى، زكاة تقديرية، وضع ليلي/فاتح، RTL، PWA

## ما يحتاج Backend لاحقًا

- مزامنة بين الأجهزة وتسجيل الدخول
- Web Push يعمل بعد إغلاق التطبيق
- أذان كامل في الخلفية على كل أنظمة التشغيل
- حساب زكاة فقهي كامل لغير النقد

## قيود معروفة

- التلاوات والبحث في القرآن يحتاجان شبكة في أول مرة.
- بوصلة القبلة تعتمد على حسّاس الجهاز؛ يتوفر بديل حسابي من الإحداثيات.
- التاريخ الهجري قد يختلف عن الرؤية الشرعية بيوم.
- الأذكار ليست موسوعة حديثية كاملة؛ كل ذكر يعرض مصدره ودرجته عند توافرها.
- الأحاديث تُعرض من HadeethEnc بدرجاتها؛ التصفح بالمصنّفات لأن البحث النصي غير متاح عبر الواجهة.
- الرقية والقصص والمساعد لا تُغني عن أهل العلم؛ المساعد للتنقّل داخل التطبيق فقط ولا يُفتي.
- راديو القرآن يحتاج شبكة، وبعض المحطات قد تتوقف مؤقتًا فتُعرض قائمة احتياطية.
